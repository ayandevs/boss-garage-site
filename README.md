# 🚗 Boss Garage Website

## 📖 Description

A responsive car garage website designed to showcase automotive services, special offers, company information, and customer contact details.

## ✨ Features

- Automotive services showcase
- Engine performance section
- Special discount offers
- Contact information and social links
- Google Maps location integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap
- jQuery
- Font Awesome

## ▶️ How to Run

1. Download or clone the project
2. Open the project in a code editor
3. Ensure all images and video files are in the "images" folder
4. Open "index.html" in a web browser
